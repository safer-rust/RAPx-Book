# Chapter 10.1. Verifying `core::slice` Safety (Challenge 17)

This case study demonstrates how RAPx verifies safety contracts in the Rust standard library's `slice` module, targeting [Challenge 17: Verify the safety of `slice` functions](https://model-checking.github.io/verify-rust-std/challenges/0017-slice.html) from the [Verify Rust Std Lib](https://github.com/model-checking/verify-rust-std) project.

## 10.1.1 Goal

Prove that all 37 challenge-listed functions in `library/core/src/slice/mod.rs` are free of undefined behavior by:

- Writing `#[rapx::requires(...)]` safety preconditions on unsafe callees
- Adding `#[rapx::verify]` annotations to trigger verification
- Running RAPx in `targeted` mode against the annotated functions

The verification must be unbounded (valid for slices of arbitrary length) and must hold for generic type `T` without monomorphization.

## 10.1.2 Tool Integration

Following the same conditional pattern as Kani (`#[cfg_attr(kani, ...)]`) and Flux (`#[cfg(flux)]`), the project uses `cfg_attr` to avoid hard-coding `register_tool` in source code:

- `core/src/lib.rs`: No `#![register_tool(rapx)]` — tool registration is injected via `RUSTFLAGS`
- `core/Cargo.toml`: `['cfg(rapx)']` declared in `[lints.rust.unexpected_cfgs]` to suppress unknown cfg warnings
- Source files: `#[cfg_attr(rapx, rapx::verify)]` and `#[cfg_attr(rapx, rapx::requires(...))]` conditionally activate only when RAPx runs

```rust
// Example from core/src/slice/mod.rs
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(a, "[0,self.len())")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(b, "[0,self.len())")))]
pub const unsafe fn swap_unchecked(&mut self, a: usize, b: usize) { /* ... */ }
```

**Run verification:**

```shell
cd library/core
RUSTFLAGS="--cfg=rapx -Zcrate-attr=feature(register_tool) -Zcrate-attr=register_tool(rapx)" \
  cargo rapx verify --module slice --mode targeted
```

> **Note:** Commands must be run from `library/core`, not the `library` workspace
> root. In the `library` workspace, `core` is only a *dependency* (the members
> are `std`, `sysroot`, `coretests`, `alloctests`), and RAPx analyzes a crate
> only when it is compiled as the primary package. Running from `library/core`
> makes `core` local, so its `#[rapx::verify]` annotations are visible without
> needing the `--crate core` filter.


The RUSTFLAGS environment variable provides three things:

| Flag | Purpose |
|------|---------|
| `--cfg=rapx` | Activates `cfg_attr(rapx, ...)` conditional expansion |
| `-Zcrate-attr=feature(register_tool)` | Enables the `register_tool` nightly feature |
| `-Zcrate-attr=register_tool(rapx)` | Registers `rapx` as a recognized tool namespace |

A GitHub Actions workflow (`.github/workflows/rapx.yml`) runs verification on every push and pull request, using the same RUSTFLAGS setup. It pins a specific RAPx commit via `RAPX_VERSION`, `cd`s into `library/core`, and invokes `cargo rapx verify --module slice --mode targeted`.

## 10.1.3 Function-by-Function Verification

This section walks through the 37 functions in the order given by the challenge, following the same pipeline as Chapter 8: **target collection → path extraction → backward slicing → symbolic VM → SMT check**. Each function entry is structured as:

- **Target** — what is verified, and the entry assumptions the verifier is allowed to make.
- **Path** — the CFG paths to each unsafe checkpoint (and loop unrolling where relevant).
- **Constraint** — the safety obligations extracted at each checkpoint and how the SMT solver discharges them.

### 10.1.3.1 Preliminaries: how the pipeline applies to `slice`

**Built-in type invariants.** Every target is a method on the primitive `[T]` (no `#[rapx::invariant]` struct), so RAPx relies on its built-in invariants for the slice receiver. On entry, a `&[T]` / `&mut [T]` parameter gets `NonNull` + `Align` + `Init` for its data pointer, plus a symbolic slice-length allocation constrained by `len >= 0` and `len * size_of::<T>() <= isize::MAX` — the facts that later discharge `Allocated` / `InBound` / `ValidPtr`. `&mut [T]` additionally grants exclusive access.

**Checkpoint kinds.** The unsafe call sites (checkpoints) in this module fall into a few families:

- `raw-ptr-deref` (`&*ptr` / `&mut *ptr`) — implicitly requires `ValidPtr` + `Align` + `Typed` (plus `Alias` for `&mut *`).
- `from_raw_parts` / `from_raw_parts_mut` — resolved via their `#[rapx::requires(NonNull, ValidPtr, Init, Alive, Alias, Align, ValidNum(size_of(T)*len <= isize::MAX))]` in `raw.rs`.
- `ptr::swap` / `ptr::copy` / `ptr::copy_nonoverlapping` / `ptr::swap_nonoverlapping` / `rotate::ptr_rotate` — resolved via the bundled JSON contract database and the effect registry.
- `SliceIndex::get_unchecked{,_mut}` — modelled as an element-strided pointer add off the slice pointer.

**Path analysis.** Most targets are acyclic (`if`/`else`), so path extraction yields one path per branch to each checkpoint. The four loop-bearing targets — `reverse`, `binary_search_by`, `partition_dedup_by`, `get_disjoint_unchecked_mut` — rely on the loop-repeat planner to unroll their loop SCC ([§8.4.5](./8.4-pipeline.md#845-auto-repeat-planner)).

**Constraint solving.** At each checkpoint the backward slicer keeps only the value chain feeding the pointer, the symbolic VM builds Z3 terms (pointer provenance, allocation bounds, path conditions), and each obligation is checked by negation-as-failure: `constraints ∧ ¬goal` → `Unsat` = `Proved`.

### 10.1.3.2 Unsafe Functions (Contract-Based)

#### get_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(index_access(self, index))))]
pub const unsafe fn get_unchecked<I>(&self, index: I) -> &I::Output
where
    I: [const] SliceIndex<Self>,
{
    unsafe { &*index.get_unchecked(self) }
}
```

**Target.** `unsafe fn` carrying its own `requires(InBound(index_access(self, index)))`. Entry facts: `&[T]` supplies a valid, in-bounds, initialized data pointer.

**Path.** Straight-line: entry → `index.get_unchecked(self)` (checkpoint) → `&*` deref (checkpoint). Two checkpoints on a single path `[0, 1]`.

**Constraint.** The `&*` deref requires `ValidPtr` + `Align` + `Typed`, discharged by the slice type invariant. The `get_unchecked` call is modelled as an element-strided pointer add off the slice pointer; its `InBound` obligation is discharged by the function's own `requires` fact. SMT: `InBound(index)` fact ∧ `¬(index in bounds)` goal → `Unsat`.

#### get_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(index_access(self, index))))]
pub const unsafe fn get_unchecked_mut<I>(&mut self, index: I) -> &mut I::Output
where
    I: [const] SliceIndex<Self>,
{
    unsafe { &mut *index.get_unchecked_mut(self) }
}
```

**Target.** Same as `get_unchecked` but `&mut [T]`, which additionally supplies exclusive `Alias` at entry.

**Path.** Identical single path `[0, 1]` to the two checkpoints.

**Constraint.** The `&mut *` deref requires `ValidPtr` + `Align` + `Typed` + `Alias`; the `Alias` obligation is discharged by the exclusive `&mut [T]` receiver. The `InBound` obligation is discharged by the `requires` fact.

#### swap_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(a, "[0,self.len())")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(b, "[0,self.len())")))]
pub const unsafe fn swap_unchecked(&mut self, a: usize, b: usize) {
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::swap_unchecked requires that the indices are within the slice",
        (len: usize = self.len(), a: usize = a, b: usize = b,) => a < len && b < len,
    );
    let ptr = self.as_mut_ptr();
    unsafe {
        ptr::swap(ptr.add(a), ptr.add(b));
    }
}
```

**Target.** `unsafe fn` with two interval preconditions `ValidNum(a, "[0,self.len())")` and `ValidNum(b, "[0,self.len())")`, which expand to `a < len && b < len`.

**Path.** Entry → `as_mut_ptr` → `ptr.add(a)` → `ptr.add(b)` → `ptr::swap` (single checkpoint). Acyclic.

**Constraint.** `ptr.add(a)` / `ptr.add(b)` each move an element stride; the `InBound` obligation on each is discharged by the interval preconditions (`a < len`, `b < len`). `ptr::swap` requires both element pointers to be dereferenceable (`ValidPtr` + `Align`), derived from the slice pointer; it allows `a == b`, so no `NonOverlap` obligation arises.

#### as_chunks_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(N, "[1,)")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(len(self) % N == 0)))]
pub const unsafe fn as_chunks_unchecked<const N: usize>(&self) -> &[[T; N]] {
    assert_unsafe_precondition!(
        check_language_ub,
        "slice::as_chunks_unchecked requires `N != 0` and the slice to split exactly into `N`-element chunks",
        (n: usize = N, len: usize = self.len()) => n != 0 && len.is_multiple_of(n),
    );
    // SAFETY: Caller must guarantee that `N` is nonzero and exactly divides the slice length
    let new_len = unsafe { exact_div(self.len(), N) };
    // SAFETY: We cast a slice of `new_len * N` elements into
    // a slice of `new_len` many `N` elements chunks.
    unsafe { from_raw_parts(self.as_ptr().cast(), new_len) }
}
```

**Target.** `unsafe fn` with `ValidNum(N, "[1,)")` (`N != 0`) and `ValidNum(len(self) % N == 0)`. `N` is a const generic (a type-level constant in the contract), so no monomorphization is needed.

**Path.** Entry → `exact_div(len, N)` (checkpoint) → `from_raw_parts` (checkpoint). Acyclic.

**Constraint.** `exact_div` requires a non-zero divisor, discharged by `N != 0`. `from_raw_parts` requires `new_len` elements of `[T; N]` to be in bounds and the byte size `≤ isize::MAX`; from `len = new_len * N` (a consequence of `len % N == 0`) the byte count is exactly the slice's own size, so `ValidPtr`/`InBound`/`ValidNum` are all discharged. The `cast` reinterprets `T` as `[T; N]` — layout-identical by construction.

#### as_chunks_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(N, "[1,)")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(len(self) % N == 0)))]
pub const unsafe fn as_chunks_unchecked_mut<const N: usize>(&mut self) -> &mut [[T; N]] {
    assert_unsafe_precondition!(
        check_language_ub,
        "slice::as_chunks_unchecked requires `N != 0` and the slice to split exactly into `N`-element chunks",
        (n: usize = N, len: usize = self.len()) => n != 0 && len.is_multiple_of(n)
    );
    let new_len = unsafe { exact_div(self.len(), N) };
    unsafe { from_raw_parts_mut(self.as_mut_ptr().cast(), new_len) }
}
```

**Target.** Same as `as_chunks_unchecked` but `&mut [T]`, so exclusive `Alias` is available at entry.

**Path.** Same two-checkpoint straight-line path.

**Constraint.** Identical to `as_chunks_unchecked`, with `from_raw_parts_mut` additionally requiring `Alias`, discharged by the `&mut self` receiver.

#### split_at_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(mid, [0,self.len()])))]
pub const unsafe fn split_at_unchecked(&self, mid: usize) -> (&[T], &[T]) {
    let len = self.len();
    let ptr = self.as_ptr();
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::split_at_unchecked requires the index to be within the slice",
        (mid: usize = mid, len: usize = len) => mid <= len,
    );
    // SAFETY: Caller has to check that `0 <= mid <= self.len()`
    unsafe { (from_raw_parts(ptr, mid), from_raw_parts(ptr.add(mid), unchecked_sub(len, mid))) }
}
```

**Target.** `unsafe fn` with the closed-interval precondition `ValidNum(mid, [0,self.len()])` → `0 <= mid <= len`.

**Path.** Entry → `from_raw_parts(ptr, mid)` (checkpoint) → `from_raw_parts(ptr.add(mid), len - mid)` (checkpoint). Acyclic.

**Constraint.** The first `from_raw_parts` requires `mid` elements in bounds — discharged by `mid <= len`. The second requires `len - mid` elements from `ptr.add(mid)` — the sub-range `[mid, len)` is in bounds and the pointer add stays within the allocation. `unchecked_sub(len, mid)` is safe because `mid <= len`. `mid == len` yields an empty right slice with a one-past-the-end pointer, which is valid.

#### split_at_mut_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(mid, [0,self.len()])))]
pub const unsafe fn split_at_mut_unchecked(&mut self, mid: usize) -> (&mut [T], &mut [T]) {
    let len = self.len();
    let ptr = self.as_mut_ptr();
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::split_at_mut_unchecked requires the index to be within the slice",
        (mid: usize = mid, len: usize = len) => mid <= len,
    );
    unsafe {
        (
            from_raw_parts_mut(ptr, mid),
            from_raw_parts_mut(ptr.add(mid), unchecked_sub(len, mid)),
        )
    }
}
```

**Target.** Same as `split_at_unchecked`, with `&mut [T]` supplying exclusive `Alias`.

**Path.** Same two-checkpoint path.

**Constraint.** Both `from_raw_parts_mut` calls require `ValidPtr` + `InBound` + `Alias`. The bounds are discharged by `0 <= mid <= len`; the two halves `[0, mid)` and `[mid, len)` are disjoint, so their `Alias` obligations are discharged by the disjointness plus the exclusive receiver.

#### align_to

```rust
#[cfg_attr(rapx, rapx::requires(ValidTransmute(T, U)))]
#[cfg_attr(rapx, rapx::verify)]
pub unsafe fn align_to<U>(&self) -> (&[T], &[U], &[T]) {
    if U::IS_ZST || T::IS_ZST {
        return (self, &[], &[]);
    }
    let ptr = self.as_ptr();
    let offset = unsafe { crate::ptr::align_offset(ptr, align_of::<U>()) };
    if offset > self.len() {
        (self, &[], &[])
    } else {
        let (left, rest) = self.split_at(offset);
        let (us_len, ts_len) = rest.align_to_offsets::<U>();
        unsafe {
            (
                left,
                from_raw_parts(rest.as_ptr() as *const U, us_len),
                from_raw_parts(rest.as_ptr().add(rest.len() - ts_len), ts_len),
            )
        }
    }
}
```

**Target.** `unsafe fn` with the type-level precondition `ValidTransmute(T, U)` — the byte-reinterpretation is axiomatized (mirroring Kani's value-level `can_dereference(middle)` contract).

**Path.** Three branch paths: (a) ZST early return — no checkpoint; (b) `offset > len` early return — no checkpoint; (c) the split-and-reinterpret path with `from_raw_parts` checkpoints. Each is acyclic.

**Constraint.** On path (c), `align_offset` (an effect-modelled call) yields a valid aligned offset; `split_at(offset)` and the two `from_raw_parts` keep the three slices contiguous and in bounds — these pointer/range facts are discharged by the range analysis. The essential risk — that the middle bytes form a valid `[U]` — is delegated to the `ValidTransmute(T, U)` axiom; RAPx verifies everything around the transmute.

#### align_to_mut

```rust
#[cfg_attr(rapx, rapx::requires(ValidTransmute(T, U)))]
#[cfg_attr(rapx, rapx::verify)]
pub unsafe fn align_to_mut<U>(&mut self) -> (&mut [T], &mut [U], &mut [T]) {
    if U::IS_ZST || T::IS_ZST {
        return (self, &mut [], &mut []);
    }
    let ptr = self.as_ptr();
    let offset = unsafe { crate::ptr::align_offset(ptr, align_of::<U>()) };
    if offset > self.len() {
        (self, &mut [], &mut [])
    } else {
        let (left, rest) = self.split_at_mut(offset);
        let (us_len, ts_len) = rest.align_to_offsets::<U>();
        let rest_len = rest.len();
        let mut_ptr = rest.as_mut_ptr();
        unsafe {
            (
                left,
                from_raw_parts_mut(mut_ptr as *mut U, us_len),
                from_raw_parts_mut(mut_ptr.add(rest_len - ts_len), ts_len),
            )
        }
    }
}
```

**Target.** Same transmute-based pattern as `align_to`, with `&mut [T]` supplying exclusive `Alias`.

**Path.** Same three branch paths; path (c) ends in two `from_raw_parts_mut` checkpoints.

**Constraint.** The three returned `&mut` slices are mutually disjoint (proved by the pointer arithmetic) and their `Alias` obligations are discharged by that disjointness plus the exclusive receiver. The transmute itself is covered by `ValidTransmute(T, U)`.

#### get_disjoint_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(index_access(self, indices))))]
#[cfg_attr(rapx, rapx::requires(NonOverlap(indices)))]
pub unsafe fn get_disjoint_unchecked_mut<I, const N: usize>(
    &mut self,
    indices: [I; N],
) -> [&mut I::Output; N]
where
    I: GetDisjointMutIndex + SliceIndex<Self>,
{
    let slice: *mut [T] = self;
    let mut arr: MaybeUninit<[&mut I::Output; N]> = MaybeUninit::uninit();
    let arr_ptr = arr.as_mut_ptr();
    unsafe {
        for i in 0..N {
            let idx = indices.get_unchecked(i).clone();
            arr_ptr.cast::<&mut I::Output>().add(i).write(&mut *slice.get_unchecked_mut(idx));
        }
        arr.assume_init()
    }
}
```

**Target.** `unsafe fn` with two preconditions that capture the contract exactly: `InBound(index_access(self, indices))` and `NonOverlap(indices)`.

**Path.** The `for i in 0..N` loop is an SCC; the loop-repeat planner unrolls it (bounded by `N`, a const generic), producing one path per iteration feeding a `get_unchecked_mut` checkpoint and a `raw-ptr-deref` checkpoint.

**Constraint.** Each `get_unchecked_mut(idx)` is discharged by `InBound`; the `&mut *` deref's `Alias` obligation is discharged by `NonOverlap(indices)` (no two returned references alias). The `MaybeUninit` array is fully written before `assume_init`, so the initialization obligation is discharged by the loop covering all `N` slots.

### 10.1.3.3 Safe Abstractions (No UB)

For the safe wrappers below there is no `requires` contract; the goal is to prove the internal `unsafe` operations cannot cause UB using only the type-level entry facts of the slice receiver.

#### first_chunk / first_chunk_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn first_chunk<const N: usize>(&self) -> Option<&[T; N]> {
    if self.len() < N {
        None
    } else {
        Some(unsafe { &*(self.as_ptr().cast_array()) })
    }
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn first_chunk_mut<const N: usize>(&mut self) -> Option<&mut [T; N]> {
    if self.len() < N {
        None
    } else {
        Some(unsafe { &mut *(self.as_mut_ptr().cast_array()) })
    }
}
```

**Target.** Safe methods; entry facts are the `&[T]` / `&mut [T]` type invariants.

**Path.** Two branches. The `len < N` branch returns `None` with no checkpoint; the `else` branch carries the path condition `len >= N` into a single `raw-ptr-deref` checkpoint.

**Constraint.** The deref requires `ValidPtr` + `Align` + `Typed` for `[T; N]`. `InBound` (the `N`-element range) is discharged by the path condition `len >= N`; `Align`, `NonNull`, `Init`, `Typed` are discharged by the slice type invariant. For `N == 0` the empty array is returned and dereferencing a dangling pointer to a zero-sized array is legal.

#### split_first_chunk / split_first_chunk_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn split_first_chunk<const N: usize>(&self) -> Option<(&[T; N], &[T])> {
    let Some((first, tail)) = self.split_at_checked(N) else { return None };
    Some((unsafe { &*(first.as_ptr().cast_array()) }, tail))
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn split_first_chunk_mut<const N: usize>(
    &mut self,
) -> Option<(&mut [T; N], &mut [T])> {
    let Some((first, tail)) = self.split_at_mut_checked(N) else { return None };
    Some((unsafe { &mut *(first.as_mut_ptr().cast_array()) }, tail))
}
```

**Target.** Safe methods; entry facts from the slice receiver.

**Path.** `split_at_checked(N)` returns `Some` only when `N <= len`; the `else` path returns `None` with no checkpoint. The `Some` path reaches one `raw-ptr-deref` checkpoint.

**Constraint.** The path condition `N <= len` (from the `Some` unwrap) guarantees `first` has exactly `N` elements, discharging the `InBound` obligation of the `cast_array` deref. The `tail` slice is returned as-is.

#### split_last_chunk / split_last_chunk_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn split_last_chunk<const N: usize>(&self) -> Option<(&[T], &[T; N])> {
    let Some(index) = self.len().checked_sub(N) else { return None };
    let (init, last) = self.split_at(index);
    Some((init, unsafe { &*(last.as_ptr().cast_array()) }))
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn split_last_chunk_mut<const N: usize>(

    let Some(index) = self.len().checked_sub(N) else { return None };
    let (init, last) = self.split_at_mut(index);
    Some((init, unsafe { &mut *(last.as_mut_ptr().cast_array()) }))
}
```

**Target.** Safe methods; entry facts from the slice receiver.

**Path.** `checked_sub(N)` returning `Some(index)` establishes `len >= N`; the `None` path returns with no checkpoint. The `Some` path reaches one `raw-ptr-deref` checkpoint.

**Constraint.** `len >= N` plus `split_at(index)` (with `index = len - N`) yields a trailing slice of exactly `N` elements, discharging the `InBound` obligation of the `cast_array` deref.

```rust
}
```

**Target.** Safe methods; entry facts from the slice receiver.

**Path.** Same as `split_last_chunk`, but only the trailing chunk is returned. `checked_sub(N)` establishes `len >= N`.

**Constraint.** The `cast_array` deref of the trailing `N`-element chunk is in bounds by `len >= N`.

#### reverse

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn reverse(&mut self) {
    let half_len = self.len() / 2;
    let Range { start, end } = self.as_mut_ptr_range();

    let (front_half, back_half) =
        unsafe {
            (
                slice::from_raw_parts_mut(start, half_len),
                slice::from_raw_parts_mut(end.sub(half_len), half_len),
            )
        };

    revswap(front_half, back_half, half_len);

    #[inline]
    const fn revswap<T>(a: &mut [T], b: &mut [T], n: usize) {
        let (a, _) = a.split_at_mut(n);
        let (b, _) = b.split_at_mut(n);
        let mut i = 0;
        #[safety::loop_invariant(i <= n)]
        while i < n {
            mem::swap(&mut a[i], &mut b[n - 1 - i]);
            i += 1;
        }
    }
}
```

**Target.** Safe method; entry facts from `&mut [T]` (including exclusive `Alias`).

**Path.** Two `from_raw_parts_mut` checkpoints on a straight-line path, followed by the `revswap` helper whose `while i < n` loop is an SCC unrolled by the repeat planner.

**Constraint.** With `half_len = len / 2`, the front half `[0, half_len)` and back half `[len - half_len, len)` are disjoint and in bounds (`len - half_len >= half_len`), discharging the `ValidPtr`/`InBound`/`Alias` obligations of both `from_raw_parts_mut` calls. Inside `revswap`, the loop invariant `i <= n` proves `a[i]` and `b[n - 1 - i]` stay in bounds, and the disjoint halves guarantee `mem::swap` never aliases.

#### as_chunks / as_chunks_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn as_chunks<const N: usize>(&self) -> (&[[T; N]], &[T]) {
    assert!(N != 0, "chunk size must be non-zero");
    let len_rounded_down = self.len() / N * N;
    let (multiple_of_n, remainder) = unsafe { self.split_at_unchecked(len_rounded_down) };
    let array_slice = unsafe { multiple_of_n.as_chunks_unchecked() };
    (array_slice, remainder)
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn as_chunks_mut<const N: usize>(&mut self) -> (&mut [[T; N]], &mut [T]) {
    assert!(N != 0, "chunk size must be non-zero");
    let len_rounded_down = self.len() / N * N;
    let (multiple_of_n, remainder) = unsafe { self.split_at_mut_unchecked(len_rounded_down) };
    let array_slice = unsafe { multiple_of_n.as_chunks_unchecked_mut() };
    (array_slice, remainder)
}
```

**Target.** Safe methods; entry facts from the slice receiver.

**Path.** Two chained checkpoints: `split_at_unchecked(len_rounded_down)` then `as_chunks_unchecked()`. Acyclic.

**Constraint.** `assert!(N != 0)` provides the path condition `N != 0`. `len_rounded_down = len / N * N` is `<= len` (discharging `split_at_unchecked`'s `mid <= len`) and a multiple of `N` (discharging `as_chunks_unchecked`'s `len % N == 0`). Both internal `unsafe` calls are thus covered by facts established in the body.

#### binary_search_by

```rust
#[cfg_attr(rapx, rapx::verify)]
pub fn binary_search_by<'a, F>(&'a self, mut f: F) -> Result<usize, usize>
where
    F: FnMut(&'a T) -> Ordering,
{
    let mut size = self.len();
    if size == 0 {
        return Err(0);
    }
    let mut base = 0usize;

    while size > 1 {
        let half = size / 2;
        let mid = base + half;
        let cmp = f(unsafe { self.get_unchecked(mid) });
        base = hint::select_unpredictable(cmp == Greater, base, mid);
        size -= half;
    }

    let cmp = f(unsafe { self.get_unchecked(base) });
    if cmp == Equal {
        unsafe { hint::assert_unchecked(base < self.len()) };
        Ok(base)
    } else {
        let result = base + (cmp == Less) as usize;
        unsafe { hint::assert_unchecked(result <= self.len()) };
        Err(result)
    }
}
```

**Target.** Safe method; entry facts from `&[T]`.

**Path.** The `while size > 1` loop is an SCC; the repeat planner unrolls it. Each iteration reaches a `get_unchecked(mid)` checkpoint; the epilogue reaches `get_unchecked(base)` plus two `assert_unchecked` hints.

**Constraint.** The loop invariant is `base + size == len` (initially `base = 0, size = len`). Each iteration computes `mid = base + half` with `half = size / 2`, so `mid < base + size == len`, discharging `get_unchecked(mid)`'s `InBound`. After `size -= half` the invariant is restored, so the unrolled loop is inductive. On exit `size <= 1`, hence `base < len`, discharging the final `get_unchecked(base)`. The two `assert_unchecked` calls are optimization hints whose bounds facts RAPx verifies independently.

#### partition_dedup_by

```rust
#[cfg_attr(rapx, rapx::verify)]
pub fn partition_dedup_by<F>(&mut self, mut same_bucket: F) -> (&mut [T], &mut [T])
where
    F: FnMut(&mut T, &mut T) -> bool,
{
    let len = self.len();
    if len <= 1 {
        return (self, &mut []);
    }

    let ptr = self.as_mut_ptr();
    let mut next_read: usize = 1;
    let mut next_write: usize = 1;

    unsafe {
        while next_read < len {
            let ptr_read = ptr.add(next_read);
            let prev_ptr_write = ptr.add(next_write - 1);
            if !same_bucket(&mut *ptr_read, &mut *prev_ptr_write) {
                if next_read != next_write {
                    let ptr_write = prev_ptr_write.add(1);
                    mem::swap(&mut *ptr_read, &mut *ptr_write);
                }
                next_write += 1;
            }
            next_read += 1;
        }
    }

    self.split_at_mut(next_write)
}
```

**Target.** Safe method; entry facts from `&mut [T]`.

**Path.** The `while next_read < len` loop is an SCC; the repeat planner unrolls it. Each iteration reaches up to three raw-pointer deref checkpoints (`ptr_read`, `prev_ptr_write`, `ptr_write`).

**Constraint.** The loop invariant is `1 <= next_write <= next_read < len`. This keeps `next_read` and `next_write - 1` in bounds and guarantees `next_read > next_write - 1`, so `ptr_read` and `prev_ptr_write` never point to the same element. When `next_read != next_write`, `ptr_read` and `ptr_write` are distinct, so `mem::swap` does not alias. RAPx proves these index facts via loop-invariant range analysis.

#### copy_within

```rust
#[cfg_attr(rapx, rapx::verify)]
pub fn copy_within<R: RangeBounds<usize>>(&mut self, src: R, dest: usize)
where
    T: Copy,
{
    let Range { start: src_start, end: src_end } = slice::range(src, ..self.len());
    let count = src_end - src_start;
    assert!(dest <= self.len() - count, "dest is out of bounds");
    unsafe {
        let ptr = self.as_mut_ptr();
        let src_ptr = ptr.add(src_start);
        let dest_ptr = ptr.add(dest);
        ptr::copy(src_ptr, dest_ptr, count);
    }
}
```

**Target.** Safe method; entry facts from `&mut [T]`.

**Path.** A single `ptr::copy` checkpoint on a straight-line path.

**Constraint.** `slice::range(src, ..self.len())` normalizes the source range and enforces `src_start <= src_end <= len`; `assert!(dest <= len - count)` enforces `dest + count <= len`. Both ranges therefore lie within `[0, len)`. `ptr::copy` permits overlap (memmove), so no `NonOverlap` obligation arises — only the in-bounds facts, which are discharged.

#### get_disjoint_check_valid

```rust
#[cfg_attr(rapx, rapx::verify)]
fn get_disjoint_check_valid<I: GetDisjointMutIndex, const N: usize>(
    indices: &[I; N],
    len: usize,
) -> Result<(), GetDisjointMutError> {
    for (i, idx) in indices.iter().enumerate() {
        if !idx.is_in_bounds(len) {
            return Err(GetDisjointMutError::IndexOutOfBounds);
        }
        for idx2 in &indices[..i] {
            if idx.is_overlapping(idx2) {
                return Err(GetDisjointMutError::OverlappingIndices);
            }
        }
    }
    Ok(())
}
```

**Target.** Safe function with no `unsafe` — it is a pure O(n²) validation loop. It is annotated with `#[rapx::verify]` so RAPx treats it as the trusted precondition generator for `get_disjoint_mut`.

**Path.** Nested loops (SCCs) over the index array; the repeat planner unrolls both.

**Constraint.** There are no unsafe checkpoints. The function's role is to prove, via its loop structure, that an `Ok` return implies every index passed `is_in_bounds` and no pair `is_overlapping` — the facts that `get_disjoint_mut` then relies on.

#### as_flattened / as_flattened_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidTransmute([T; N], T)))]
pub const fn as_flattened(&self) -> &[T] {
    let len = if T::IS_ZST {
        self.len().checked_mul(N).expect("slice len overflow")
    } else {
        unsafe { self.len().unchecked_mul(N) }
    };
    unsafe { from_raw_parts(self.as_ptr().cast(), len) }
}

#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidTransmute([T; N], T)))]
pub const fn as_flattened_mut(&mut self) -> &mut [T] {
    let len = if T::IS_ZST {
        self.len().checked_mul(N).expect("slice len overflow")
    } else {
        unsafe { self.len().unchecked_mul(N) }
    };
    unsafe { from_raw_parts_mut(self.as_mut_ptr().cast(), len) }
}
```

**Target.** Safe methods, but annotated with the type-level axiom `ValidTransmute([T; N], T)` (layout identity of `[T; N]` and `N × T`). Entry facts from the slice receiver.

**Path.** A single `from_raw_parts` / `from_raw_parts_mut` checkpoint.

**Constraint.** The new length is `len * N`: for ZSTs `checked_mul` guards overflow; for non-ZSTs the multiplication cannot overflow because the slice is already in the address space. `from_raw_parts` requires `len * N` elements of `T` (i.e. `len * size_of::<[T; N]>()` bytes) in bounds, which follows from the slice's own validity.
