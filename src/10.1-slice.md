# Chapter 10.1. Verifying `core::slice` Safety (Challenge 17)

This case study demonstrates how RAPx verifies safety contracts in the Rust standard library's `slice` module, targeting [Challenge 17: Verify the safety of `slice` functions](https://model-checking.github.io/verify-rust-std/challenges/0017-slice.html) from the [Verify Rust Std Lib](https://github.com/model-checking/verify-rust-std) project.

## 10.1.1 Goal

Prove that all 37 challenge-listed functions in `library/core/src/slice/mod.rs` are free of undefined behavior by:

- Writing `#[rapx::requires(...)]` safety preconditions on unsafe callees
- Adding `#[rapx::verify]` annotations to trigger verification
- Running RAPx in `targeted` mode against the annotated functions

The verification must be unbounded (valid for slices of arbitrary length) and must hold for generic type `T` without monomorphization.

## 10.1.2 Tool Integration

Following the same conditional pattern as Kani (`#[cfg_attr(kani, ...)]`) and Flux (`#[cfg(flux)]`), the project uses `cfg_attr` to avoid hard-coding `register_tool` in source code:

- `core/src/lib.rs`: No `#![register_tool(rapx)]` — tool registration is injected via `RUSTFLAGS`
- `core/Cargo.toml`: `['cfg(rapx)']` declared in `[lints.rust.unexpected_cfgs]` to suppress unknown cfg warnings
- Source files: `#[cfg_attr(rapx, rapx::verify)]` and `#[cfg_attr(rapx, rapx::requires(...))]` conditionally activate only when RAPx runs

```rust
// Example from core/src/slice/mod.rs

#[cfg_attr(rapx, rapx::requires(ValidNum(a, "[0,self.len())")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(b, "[0,self.len())")))]
pub const unsafe fn swap_unchecked(&mut self, a: usize, b: usize) { /* ... */ }
```

```rust

pub unsafe fn copy_nonoverlapping<T>(src: *const T, dst: *mut T, count: usize) { /* ... */ }
```

**Run verification:**

```shell
  cargo rapx verify --module slice --mode targeted
```

> root. In the `library` workspace, `core` is only a *dependency* (the members

> only when it is compiled as the primary package. Running from `library/core`

## 10.1.6 Function-by-Function Verification

This section walks through the 37 functions in the order given by the challenge, giving each function's body and how RAPx verifies it. The functions fall into three verification patterns:

1. **Contract-based unsafe functions** — the `#[rapx::requires(...)]` precondition directly covers the out-of-bounds / aliasing risk, and the body is checked against it.
2. **Safe abstractions** — safe guards (`if len < N`, `assert!`, `checked_sub`, `?`) establish the path condition that discharges the internal `unsafe` operation's precondition (typically `InBound`).
3. **Transmute-based functions** (`align_to*`, `as_simd*`, `as_flattened*`) — the byte re-interpretation relies on the type-level axiom `ValidTransmute(T, U)`; the pointer arithmetic around it is still verified.

### 10.1.6.1 Unsafe Functions (Contract-Based)

#### get_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(index_access(self, index))))]
pub const unsafe fn get_unchecked<I>(&self, index: I) -> &I::Output
where
    I: [const] SliceIndex<Self>,
{
    unsafe { &*index.get_unchecked(self) }
}
```

**Verification:** `SliceIndex::get_unchecked` is modelled by RAPx as an element-strided pointer addition off the slice pointer (`eff_sliceindex_get_unchecked`). The `&*` dereference demands `NonNull` and `Align`, which are derived from the slice reference being valid. The out-of-bounds risk is discharged directly by the `InBound(index_access(self, index))` precondition.

#### get_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(index_access(self, index))))]
pub const unsafe fn get_unchecked_mut<I>(&mut self, index: I) -> &mut I::Output
where
    I: [const] SliceIndex<Self>,
{
    unsafe { &mut *index.get_unchecked_mut(self) }
}
```

**Verification:** Identical to `get_unchecked`, except the mutable reference additionally requires exclusive aliasing. Since `self` is `&mut [T]`, the `Alias` property is satisfied by Rust's borrow rules.

#### swap_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(a, "[0,self.len())")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(b, "[0,self.len())")))]
pub const unsafe fn swap_unchecked(&mut self, a: usize, b: usize) {
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::swap_unchecked requires that the indices are within the slice",
        (len: usize = self.len(), a: usize = a, b: usize = b,) => a < len && b < len,
    );
    let ptr = self.as_mut_ptr();
    unsafe {
        ptr::swap(ptr.add(a), ptr.add(b));
    }
}
```

**Verification:** The two `ValidNum(a, "[0,self.len())")` / `ValidNum(b, "[0,self.len())")` preconditions expand to `a < len && b < len`, exactly matching the safety contract. `ptr.add(a)` / `ptr.add(b)` each dereference one element; the interval bounds discharge the out-of-bounds check. `ptr::swap` is allowed when `a == b`, so no aliasing conflict arises.

#### as_chunks_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(N, "[1,)")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(len(self) % N == 0)))]
pub const unsafe fn as_chunks_unchecked<const N: usize>(&self) -> &[[T; N]] {
    assert_unsafe_precondition!(
        check_language_ub,
        "slice::as_chunks_unchecked requires `N != 0` and the slice to split exactly into `N`-element chunks",
        (n: usize = N, len: usize = self.len()) => n != 0 && len.is_multiple_of(n),
    );
    // SAFETY: Caller must guarantee that `N` is nonzero and exactly divides the slice length
    let new_len = unsafe { exact_div(self.len(), N) };
    // SAFETY: We cast a slice of `new_len * N` elements into
    // a slice of `new_len` many `N` elements chunks.
    unsafe { from_raw_parts(self.as_ptr().cast(), new_len) }
}
```

**Verification:** `ValidNum(N, "[1,)")` means `N != 0`, guaranteeing `exact_div` does not divide by zero. `ValidNum(len(self) % N == 0)` means `len` is a multiple of `N`, so `new_len * N == len`. The `cast` re-interprets `T` as `[T; N]`; `from_raw_parts` requires `new_len` elements of `[T; N]` (i.e. `len * size_of::<T>()` bytes) to be in bounds, which follows from `new_len * N == len`.

#### as_chunks_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(N, "[1,)")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(len(self) % N == 0)))]
pub const unsafe fn as_chunks_unchecked_mut<const N: usize>(&mut self) -> &mut [[T; N]] {
    assert_unsafe_precondition!(
        check_language_ub,
        "slice::as_chunks_unchecked requires `N != 0` and the slice to split exactly into `N`-element chunks",
        (n: usize = N, len: usize = self.len()) => n != 0 && len.is_multiple_of(n)
    );
    let new_len = unsafe { exact_div(self.len(), N) };
    unsafe { from_raw_parts_mut(self.as_mut_ptr().cast(), new_len) }
}
```

**Verification:** Same as `as_chunks_unchecked`, using `from_raw_parts_mut`. The mutable variant additionally requires exclusive aliasing, satisfied by `&mut self`.

#### split_at_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(mid, [0,self.len()])))]
pub const unsafe fn split_at_unchecked(&self, mid: usize) -> (&[T], &[T]) {
    let len = self.len();
    let ptr = self.as_ptr();
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::split_at_unchecked requires the index to be within the slice",
        (mid: usize = mid, len: usize = len) => mid <= len,
    );
    // SAFETY: Caller has to check that `0 <= mid <= self.len()`
    unsafe { (from_raw_parts(ptr, mid), from_raw_parts(ptr.add(mid), unchecked_sub(len, mid))) }
}
```

**Verification:** The closed-interval precondition `ValidNum(mid, [0,self.len()])` expands to `0 <= mid <= len`. The left slice `from_raw_parts(ptr, mid)` covers `[0, mid)` and the right slice `from_raw_parts(ptr.add(mid), len - mid)` covers `[mid, len)`; both are in bounds and non-overlapping. When `mid == len`, the right slice is empty with a one-past-the-end pointer, which is valid.

#### split_at_mut_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(mid, [0,self.len()])))]
pub const unsafe fn split_at_mut_unchecked(&mut self, mid: usize) -> (&mut [T], &mut [T]) {
    let len = self.len();
    let ptr = self.as_mut_ptr();
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::split_at_mut_unchecked requires the index to be within the slice",
        (mid: usize = mid, len: usize = len) => mid <= len,
    );
    unsafe {
        (
            from_raw_parts_mut(ptr, mid),
            from_raw_parts_mut(ptr.add(mid), unchecked_sub(len, mid)),
        )
    }
}
```

**Verification:** Same as `split_at_unchecked`, using `from_raw_parts_mut`. The two halves are disjoint by construction and mutually exclusive, satisfying the `NonOverlap`/`Alias` requirements of `from_raw_parts_mut`.

#### align_to

```rust
#[cfg_attr(rapx, rapx::requires(ValidTransmute(T, U)))]
#[cfg_attr(rapx, rapx::verify)]
pub unsafe fn align_to<U>(&self) -> (&[T], &[U], &[T]) {
    if U::IS_ZST || T::IS_ZST {
        return (self, &[], &[]);
    }
    let ptr = self.as_ptr();
    let offset = unsafe { crate::ptr::align_offset(ptr, align_of::<U>()) };
    if offset > self.len() {
        (self, &[], &[])
    } else {
        let (left, rest) = self.split_at(offset);
        let (us_len, ts_len) = rest.align_to_offsets::<U>();
        unsafe {
            (
                left,
                from_raw_parts(rest.as_ptr() as *const U, us_len),
                from_raw_parts(rest.as_ptr().add(rest.len() - ts_len), ts_len),
            )
        }
    }
}
```

**Verification:** This is a transmute-based function. The ZST branch returns `(self, &[], &[])` directly. Otherwise `align_offset` computes the alignment split; `split_at` and the two `from_raw_parts` calls keep the three slices contiguous and in bounds (verified by RAPx's pointer/range analysis). The essential safety risk — that the middle bytes form a valid `[U]` — is delegated to the type-level axiom `ValidTransmute(T, U)` (mirroring Kani's value-level `can_dereference(middle)` contract).

#### align_to_mut

```rust
#[cfg_attr(rapx, rapx::requires(ValidTransmute(T, U)))]
#[cfg_attr(rapx, rapx::verify)]
pub unsafe fn align_to_mut<U>(&mut self) -> (&mut [T], &mut [U], &mut [T]) {
    if U::IS_ZST || T::IS_ZST {
        return (self, &mut [], &mut []);
    }
    let ptr = self.as_ptr();
    let offset = unsafe { crate::ptr::align_offset(ptr, align_of::<U>()) };
    if offset > self.len() {
        (self, &mut [], &mut [])
    } else {
        let (left, rest) = self.split_at_mut(offset);
        let (us_len, ts_len) = rest.align_to_offsets::<U>();
        let rest_len = rest.len();
        let mut_ptr = rest.as_mut_ptr();
        unsafe {
            (
                left,
                from_raw_parts_mut(mut_ptr as *mut U, us_len),
                from_raw_parts_mut(mut_ptr.add(rest_len - ts_len), ts_len),
            )
        }
    }
}
```

**Verification:** Same transmute-based pattern as `align_to`, using `split_at_mut` and `from_raw_parts_mut`. Exclusive aliasing across the three returned `&mut` slices is guaranteed by their disjointness (proved by the pointer arithmetic) and by `&mut self`.

#### get_disjoint_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(index_access(self, indices))))]
#[cfg_attr(rapx, rapx::requires(NonOverlap(indices)))]
pub unsafe fn get_disjoint_unchecked_mut<I, const N: usize>(
    &mut self,
    indices: [I; N],
) -> [&mut I::Output; N]
where
    I: GetDisjointMutIndex + SliceIndex<Self>,
{
    let slice: *mut [T] = self;
    let mut arr: MaybeUninit<[&mut I::Output; N]> = MaybeUninit::uninit();
    let arr_ptr = arr.as_mut_ptr();
    unsafe {
        for i in 0..N {
            let idx = indices.get_unchecked(i).clone();
            arr_ptr.cast::<&mut I::Output>().add(i).write(&mut *slice.get_unchecked_mut(idx));
        }
        arr.assume_init()
    }
}
```

**Verification:** The two preconditions capture the contract exactly: `InBound(index_access(self, indices))` guarantees every index is in bounds, and `NonOverlap(indices)` guarantees the returned `&mut` references never alias. The loop writes every slot of the `MaybeUninit` array before `assume_init`, discharging the initialization requirement.

### 10.1.6.2 Safe Abstractions (No UB)

#### first_chunk / first_chunk_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn first_chunk<const N: usize>(&self) -> Option<&[T; N]> {
    if self.len() < N {
        None
    } else {
        Some(unsafe { &*(self.as_ptr().cast_array()) })
    }
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn first_chunk_mut<const N: usize>(&mut self) -> Option<&mut [T; N]> {
    if self.len() < N {
        None
    } else {
        Some(unsafe { &mut *(self.as_mut_ptr().cast_array()) })
    }
}
```

**Verification:** The unsafe operation is `&*ptr.cast_array()`, dereferencing the slice pointer re-interpreted as `*const [T; N]`. The guard `self.len() < N` makes the `else` branch carry the path condition `len >= N`, which discharges the `InBound` requirement for `N` elements. `NonNull`, `Align`, `Init` follow from the slice reference being valid; `Alias` follows from shared-reference-to-shared-reference (or `&mut` exclusive) derivation. For `N == 0` the empty array is returned, and dereferencing a dangling pointer to a zero-sized array is legal.

#### split_first_chunk / split_first_chunk_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn split_first_chunk<const N: usize>(&self) -> Option<(&[T; N], &[T])> {
    let Some((first, tail)) = self.split_at_checked(N) else { return None };
    Some((unsafe { &*(first.as_ptr().cast_array()) }, tail))
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn split_first_chunk_mut<const N: usize>(
    &mut self,
) -> Option<(&mut [T; N], &mut [T])> {
    let Some((first, tail)) = self.split_at_mut_checked(N) else { return None };
    Some((unsafe { &mut *(first.as_mut_ptr().cast_array()) }, tail))
}
```

**Verification:** `split_at_checked(N)` / `split_at_mut_checked(N)` return `Some` only when `N <= len`, guaranteeing `first` has exactly `N` elements. The `cast_array` dereference is therefore in bounds; the `tail` slice is returned unchanged.

#### split_last_chunk / split_last_chunk_mut

#### reverse

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn reverse(&mut self) {
    let half_len = self.len() / 2;
    let Range { start, end } = self.as_mut_ptr_range();

    let (front_half, back_half) =
        unsafe {
            (
                slice::from_raw_parts_mut(start, half_len),
                slice::from_raw_parts_mut(end.sub(half_len), half_len),
            )
        };

    revswap(front_half, back_half, half_len);

    #[inline]
    const fn revswap<T>(a: &mut [T], b: &mut [T], n: usize) {
        let (a, _) = a.split_at_mut(n);
        let (b, _) = b.split_at_mut(n);
        let mut i = 0;
        #[safety::loop_invariant(i <= n)]
        while i < n {
            mem::swap(&mut a[i], &mut b[n - 1 - i]);
            i += 1;
        }
    }
}
```

**Verification:** With `half_len = len / 2`, the front half `[0, half_len)` and back half `[len - half_len, len)` are disjoint and in bounds (since `len - half_len >= half_len`). The two `from_raw_parts_mut` calls are therefore valid and non-aliasing. In `revswap`, the loop invariant `i <= n` (tracked by RAPx's loop analysis) proves `a[i]` and `b[n - 1 - i]` stay in bounds, and the disjoint halves guarantee `mem::swap` never aliases.

#### as_chunks / as_chunks_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn as_chunks<const N: usize>(&self) -> (&[[T; N]], &[T]) {
    assert!(N != 0, "chunk size must be non-zero");
    let len_rounded_down = self.len() / N * N;
    let (multiple_of_n, remainder) = unsafe { self.split_at_unchecked(len_rounded_down) };
    let array_slice = unsafe { multiple_of_n.as_chunks_unchecked() };
    (array_slice, remainder)
}

#[cfg_attr(rapx, rapx::verify)]
pub const fn as_chunks_mut<const N: usize>(&mut self) -> (&mut [[T; N]], &mut [T]) {
    assert!(N != 0, "chunk size must be non-zero");
    let len_rounded_down = self.len() / N * N;
    let (multiple_of_n, remainder) = unsafe { self.split_at_mut_unchecked(len_rounded_down) };
    let array_slice = unsafe { multiple_of_n.as_chunks_unchecked_mut() };
    (array_slice, remainder)
}
```

**Verification:** `assert!(N != 0)` discharges the `N != 0` precondition. `len_rounded_down = len / N * N` is `<= len` (satisfying `split_at_unchecked`'s `mid <= len`) and a multiple of `N` (satisfying `as_chunks_unchecked`'s `len % N == 0`). Both internal `unsafe` calls are thus covered.

#### as_rchunks

```rust
#[cfg_attr(rapx, rapx::verify)]
pub const fn as_rchunks<const N: usize>(&self) -> (&[T], &[[T; N]]) {
    assert!(N != 0, "chunk size must be non-zero");
    let len = self.len() / N;
    let (remainder, multiple_of_n) = self.split_at(self.len() - len * N);
    let array_slice = unsafe { multiple_of_n.as_chunks_unchecked() };

}
```

**Verification:** `assert!(N != 0)` covers the non-zero requirement. `self.len() - len * N` equals the remainder `len % N`, so the right slice `multiple_of_n` has a length that is a multiple of `N`, satisfying `as_chunks_unchecked`'s precondition. The left remainder has length `< N` by construction.

#### binary_search_by

```rust
#[cfg_attr(rapx, rapx::verify)]
pub fn binary_search_by<'a, F>(&'a self, mut f: F) -> Result<usize, usize>
where
    F: FnMut(&'a T) -> Ordering,
{
    let mut size = self.len();
    if size == 0 {
        return Err(0);
    }
    let mut base = 0usize;

    while size > 1 {
        let half = size / 2;
        let mid = base + half;
        let cmp = f(unsafe { self.get_unchecked(mid) });
        base = hint::select_unpredictable(cmp == Greater, base, mid);
        size -= half;
    }

    let cmp = f(unsafe { self.get_unchecked(base) });
    if cmp == Equal {
        unsafe { hint::assert_unchecked(base < self.len()) };
        Ok(base)
    } else {
        let result = base + (cmp == Less) as usize;
        unsafe { hint::assert_unchecked(result <= self.len()) };
        Err(result)
    }
}
```

**Verification:** The loop invariant is `base + size == len`. Initially `base = 0`, `size = len`. Each iteration sets `mid = base + half` with `half = size / 2`, so `mid < base + size == len`; `get_unchecked(mid)` is in bounds. After `size -= half`, the invariant is restored. On exit `size <= 1`, so `base < len` and the final `get_unchecked(base)` is in bounds. The `assert_unchecked` calls are optimization hints; RAPx verifies the bounds facts via path-sensitive range analysis over the loop.

#### partition_dedup_by

```rust
#[cfg_attr(rapx, rapx::verify)]
pub fn partition_dedup_by<F>(&mut self, mut same_bucket: F) -> (&mut [T], &mut [T])
where
    F: FnMut(&mut T, &mut T) -> bool,
{
    let len = self.len();
    if len <= 1 {
        return (self, &mut []);
    }

    let ptr = self.as_mut_ptr();
    let mut next_read: usize = 1;
    let mut next_write: usize = 1;

    unsafe {
        while next_read < len {
            let ptr_read = ptr.add(next_read);
            let prev_ptr_write = ptr.add(next_write - 1);
            if !same_bucket(&mut *ptr_read, &mut *prev_ptr_write) {
                if next_read != next_write {
                    let ptr_write = prev_ptr_write.add(1);
                    mem::swap(&mut *ptr_read, &mut *ptr_write);
                }
                next_write += 1;
            }
            next_read += 1;
        }
    }

    self.split_at_mut(next_write)
}
```

**Verification:** The loop maintains `1 <= next_write <= next_read < len`. Hence `next_read` and `next_write - 1` are in bounds, and `next_read > next_write - 1` ensures `ptr_read` and `prev_ptr_write` never point to the same element. When `next_read != next_write`, `ptr_read` and `ptr_write` are distinct, so `mem::swap` does not alias. RAPx proves these index bounds and disjointness via loop-invariant range analysis.

#### copy_within

```rust
#[cfg_attr(rapx, rapx::verify)]
pub fn copy_within<R: RangeBounds<usize>>(&mut self, src: R, dest: usize)
where
    T: Copy,
{
    let Range { start: src_start, end: src_end } = slice::range(src, ..self.len());
    let count = src_end - src_start;
    assert!(dest <= self.len() - count, "dest is out of bounds");
    unsafe {
        let ptr = self.as_mut_ptr();
        let src_ptr = ptr.add(src_start);
        let dest_ptr = ptr.add(dest);
        ptr::copy(src_ptr, dest_ptr, count);
    }
}
```

**Verification:** `slice::range(src, ..self.len())` normalizes the source range and enforces `src_start <= src_end <= len`. `assert!(dest <= len - count)` enforces `dest + count <= len`. Both source and destination ranges therefore lie within `[0, len)`. `ptr::copy` permits overlap (memmove semantics), so no `NonOverlap` precondition is required — only the in-bounds fact, which is discharged.

#### get_disjoint_mut

**Verification:** `get_disjoint_check_valid(...)?` returning `Ok` proves all indices are in bounds and pairwise non-overlapping. #### get_disjoint_check_valid

```rust
#[cfg_attr(rapx, rapx::verify)]
fn get_disjoint_check_valid<I: GetDisjointMutIndex, const N: usize>(
    indices: &[I; N],
    len: usize,
) -> Result<(), GetDisjointMutError> {
    for (i, idx) in indices.iter().enumerate() {
        if !idx.is_in_bounds(len) {
            return Err(GetDisjointMutError::IndexOutOfBounds);
        }
        for idx2 in &indices[..i] {
            if idx.is_overlapping(idx2) {
                return Err(GetDisjointMutError::OverlappingIndices);
            }
        }
    }
    Ok(())
}
```

**Verification:** This function contains no `unsafe` — it is a pure O(n²) validation loop over the indices (`is_in_bounds` and `is_overlapping`). It is annotated with `#[rapx::verify]` so RAPx can use it as the trusted precondition generator for `get_disjoint_mut`: an `Ok` return is interpreted as establishing `InBound ∧ NonOverlap` at the call site.

#### as_flattened / as_flattened_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidTransmute([T; N], T)))]
pub const fn as_flattened(&self) -> &[T] {
    let len = if T::IS_ZST {
        self.len().checked_mul(N).expect("slice len overflow")
    } else {
        unsafe { self.len().unchecked_mul(N) }
    };
    unsafe { from_raw_parts(self.as_ptr().cast(), len) }
}

#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidTransmute([T; N], T)))]
pub const fn as_flattened_mut(&mut self) -> &mut [T] {
    let len = if T::IS_ZST {
        self.len().checked_mul(N).expect("slice len overflow")
    } else {
        unsafe { self.len().unchecked_mul(N) }
    };
    unsafe { from_raw_parts_mut(self.as_mut_ptr().cast(), len) }
}
```

**Verification:** The `cast` re-interprets `[T; N]` as `T`; `ValidTransmute([T; N], T)` is the layout-identity axiom. The new length is `len * N`: for ZSTs `checked_mul` guards overflow; for non-ZSTs the multiplication cannot overflow because the slice is already in the address space. `from_raw_parts` requires `len * N` elements of `T` (i.e. `len * size_of::<[T; N]>()` bytes) to be in bounds, which follows from the slice's own validity.
