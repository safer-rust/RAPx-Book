# Chapter 10.1. Verifying `core::slice` Safety (Challenge 17)

This case study demonstrates how RAPx verifies safety contracts in the Rust standard library's `slice` module, targeting [Challenge 17: Verify the safety of `slice` functions](https://model-checking.github.io/verify-rust-std/challenges/0017-slice.html) from the [Verify Rust Std Lib](https://github.com/model-checking/verify-rust-std) project.

## 10.1.1 Goal

Prove that all 37 challenge-listed functions in `library/core/src/slice/mod.rs` are free of undefined behavior by:

- Writing `#[rapx::requires(...)]` safety preconditions on unsafe callees
- Adding `#[rapx::verify]` annotations to trigger verification
- Running RAPx in `targeted` mode against the annotated functions

The verification must be unbounded (valid for slices of arbitrary length) and must hold for generic type `T` without monomorphization.

## 10.1.2 Tool Integration

Like Kani (`#[cfg_attr(kani, ...)]`), RAPx annotations use `cfg_attr` so they only activate when the tool runs — `register_tool` is injected via `RUSTFLAGS`, never hard-coded in source:

```rust
// core/src/slice/mod.rs
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(a, "[0,self.len())")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(b, "[0,self.len())")))]
pub const unsafe fn swap_unchecked(&mut self, a: usize, b: usize) { /* ... */ }
```

Run from `library/core` (not the workspace root — `core` must be the primary package, not a dependency, for its annotations to be visible):

```shell
cd library/core
RUSTFLAGS="--cfg=rapx -Zcrate-attr=feature(register_tool) -Zcrate-attr=register_tool(rapx)" \
  cargo rapx verify --module slice --mode targeted
```

- `--cfg=rapx` activates the `cfg_attr(rapx, ...)` expansion.
- `-Zcrate-attr=feature(register_tool) -Zcrate-attr=register_tool(rapx)` registers `rapx` as a tool namespace.

A GitHub Actions workflow (`.github/workflows/rapx.yml`) runs the same command on every push and PR, pinning a RAPx commit via `RAPX_VERSION`.

## 10.1.3 Function-by-Function Verification

**Slice type invariant.** Every target is a method on the primitive `[T]` (no `#[rapx::invariant]` struct), so RAPx relies on the slice type invariant declared in `std-type-invariants.json` under the `[T]` key — established by `init_parameters` at entry and re-proved at `return`:

```json
"[T]": {
  "invariants": [
    { "tag": "NonNull", "args": ["$self"] },
    { "tag": "Align", "args": ["$self", "$elem"] },
    { "tag": "ValidNum", "args": ["size_of($elem) * len($self) <= isize::MAX"] },
    { "tag": "Allocated", "args": ["$self", "$elem", "len($self)"] },
    { "tag": "Init", "args": ["$self", "$elem", "len($self)"] }
  ]
}
```

**Symbolic resolution.** `$self` instantiates to the slice reference and `$elem` to the element type `T`. For a generic `T`, its size and alignment are unknown, so RAPx represents them symbolically as `sizeof_T` and `align_T` (`sizeof_T ≥ 0` — `T` may be a ZST — and `align_T ≥ 1`, linked by the layout constraint `sizeof_T % align_T == 0`); the slice length is likewise symbolic, written `len`. The atoms therefore resolve to:

- `NonNull($self)` → `self.term ≠ 0`
- `Align($self, $elem)` → `self.term % align_T == 0`
- `ValidNum(size_of($elem) * len($self) <= isize::MAX)` → `len * sizeof_T ≤ isize::MAX`
- `Allocated($self, $elem, len($self))` → `Allocated(self, T, len)`
- `Init($self, $elem, len($self))` → `Init(self, T, len)`

The following traces cite these symbolic forms directly. `NonNull` and `Align` hold for every slice — even an empty one, whose dangling data pointer (`NonNull::dangling`) is still non-null and properly aligned (Rust requires alignment for size-0 access). `Allocated` and `Init` also hold unconditionally: an empty slice (`len == 0`) has zero elements, so both are vacuous.

### 10.1.3.1 get_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(self, index)))]
pub const unsafe fn get_unchecked<I>(&self, index: I) -> &I::Output
where
    I: [const] SliceIndex<Self>,
{
    unsafe { &*index.get_unchecked(self) }
}
```

**Verification Targets.** The body `&*index.get_unchecked(self)` desugars into two unsafe operations:

(1) `index.get_unchecked(self)` — the `SliceIndex::get_unchecked` trait call, returning a raw pointer `*const Output`.

(2) `&*ptr` — the raw-pointer dereference that turns that pointer back into a reference. RAPx models this as a `Ptr2Ref(p, T)` checkpoint, decomposed into four obligations: `Init(p, T, 1)` + `ValidPtr(p, T, 1)` + `Align(p, T)` + `Alias(p)`, where `ValidPtr = NonNull + Deref`.

Besides these, the `&[T]` receiver's slice type invariant is re-proved at the function's `return` block.

**Path.** The two unsafe operations sit on the normal path `bb0 → bb1` (`get_unchecked` in `bb0`, the `&*` deref in `bb1`). The call's unwind edge to `bb2` (`resume`, the panic path) is also part of the CFG, so RAPx's path graph enumerates it — but `bb2` holds no unsafe checkpoint, so it adds no obligation. The `&[T]` invariant is re-proved only at the `return` block `bb1` — a type invariant is a normal-return postcondition, so the panic-unwind path carries none.

**MIR** (compiled with `nightly-2026-02-05`; locals `_1` = `self`, `_2` = `index`):

```text
bb0: _5 = move _2;
     _6 = &raw const (*_1);
     _4 = <I as SliceIndex<[T]>>::get_unchecked(move _5, move _6) -> [return: bb1, unwind: bb2];
bb1: _3 = &(*_4);   // &* — raw-pointer deref (Ptr2Ref checkpoint)
     _0 = &(*_3);   // safe reborrow, no checkpoint
     return;
bb2 (cleanup): resume;
```

**Verification.** The VM steps the path statement by statement. Each local is a symbolic `VmValue` (`term` = address/value, `prov` = `(alloc, offset)`, plus flags `non_null`/`aligned`/`init`); `alloc(x)` is the `Allocation` a local points into, holding `base`/`size`/`align`.

The `#[rapx::requires]` fact (`InBound`) is recorded at entry as the numeric bound `index < len` (a path condition), while the slice type invariant (`NonNull`/`Align`/`ValidNum(size_of(T)*len <= isize::MAX)`/`Allocated`/`Init`) is established by `init_parameters` itself and re-proved at return. Each `InBound` checkpoint is discharged by SMT over that recorded bound and the allocation's `base`/`size`. For a generic `T` the element size is a *shared symbolic constant* `sizeof_T` (≥ 0, so `T` may be a ZST) rather than a monomorphized byte count, so the data allocation's byte size is `len*sizeof_T`; the element alignment is likewise a shared symbolic `align_T` (≥ 1), tied to the size by the layout constraint `sizeof_T % align_T == 0`. The slice length is materialized on the allocation as `slice_len` (mirroring the fat pointer's metadata word), with `size = slice_len * sizeof_T`, so `len()` reads it directly. The path, step by step:

```text
entry   _1 = self (&[T]), _2 = index (I)

          init_parameters:
            data_alloc.align = align_T, data_alloc.slice_len = len, data_alloc.size = len * sizeof_T, data_alloc.element_ty = T
            _1.term = data_alloc.base, _1.prov = (data_alloc, 0), _1.flags = { non_null, aligned, init, in_bounds }
               slice type invariant (JSON `[T]` entry):
                 NonNull(_1)           : _1.term ≠ 0
                 Align(_1, T)          : _1.term % align_T == 0
                 ValidNum(..)          : len * sizeof_T ≤ isize::MAX
                 Allocated(_1, T, len) : len·sizeof_T ≤ data_alloc.size
                 Init(_1, T, len)      : data_alloc.initialized = true   (whole slice data initialized)
               entry fact: len ≥ 0              (usize non-negativity)
            _2.term = param_2 (fresh symbolic)

          caller contracts (asserted as facts):
            InBound(_1, _2)      →  _2.term < len

_5 = move _2
          VM  _5.term = _2.term

_6 = &raw const (*_1)
          VM  _6.term = _1.term, _6.prov = _1.prov, _6.flags = { non_null, in_bounds }, _6.align_n = data_alloc.align = align_T

_4 = get_unchecked(move _5, move _6)                    [checkpoint (1)]
          check  InBound(_6, _5)   ←  SMT: assert entry `_2.term < len`; assert ¬(`_5.term < len`); `_5.term` ≡ `_2.term` ⇒ UNSAT    Proved
          VM  _4.term = _6.term + _5.term*sizeof_T, _4.prov = (data_alloc, _6.offset + _5.term*sizeof_T), _4.flags = { non_null, in_bounds }

_3 = &(*_4)                                             [checkpoint (2)]
          check  Init(_4, T, 1)      ←  data_alloc.initialized = true                                     Proved
          check  NonNull(_4)         ←  non_null ∈ _4.flags                                             Proved
          check  Allocated(_4, T, 1) ←  SMT: assert ¬(`(_5.term+1)*sizeof_T ≤ len*sizeof_T`)
                                            — case split on `sizeof_T`: ZST (`= 0`, both sides 0) and
                                              non-ZST (`≥ 1`, unsat by `_5.term < len`) ⇒ UNSAT    Proved
          check  InBound(_4, T, 1)   ←  in_bounds ∈ _4.flags, count == 1 (single-element fast-path)    Proved
          check  Align(_4, T)        ←  required align = align_T; real align_n = align_T ⇒ proved    Proved
          check  Alias(_4)           ←  (hazard) resolve_origin(_4) → _1 (&self, shared) ⇒ shared view safe    Proved
          VM  _3.term = _4.term, _3.prov = _4.prov, _3.flags = { non_null, aligned, init, in_bounds }

_0 = &(*_3)
          VM  _0.term = _3.term, _0.prov = _3.prov, _0.flags = { non_null, aligned, init, in_bounds }

return                                                   [type-invariant]
          check  NonNull + Align + ValidNum + Allocated + Init  ←  _1 unchanged    Proved

result: SOUND
```

**Formal reasoning rules.** The proof is discharged by the following deduction rules, using the notation declared at the top of the block:

```text
Notation:  S = sizeof_T,  A = align_T,  s : &[T],  len = s.len(),
           prov(p) = (a, off)  ⇔  p points into allocation a at byte offset off

── Slice type invariant ──
NonNull(s) ∧ Align(s, T) ∧ ValidNum(len·S ≤ isize::MAX) ∧ Allocated(s, T, len) ∧ Init(s, T, len)

── Layout ──
──────────        ──────────        ──────────────────         ────────
S ≥ 0             A ≥ 1             S % A == 0                 len ≥ 0

── Allocation (s : &[T]) ──
prov(s) = (a, 0)   a.slice_len = len   a.size = len·S   a.align = A   a.initialized = true

── Pointer identity ──
prov(p) = (a, off)
─────────────────────
p.term = a.base + off

── Pointer arithmetic ──
prov(p) = (a, off)                      prov(p) = (a, off)
──────────────────────────────          ──────────────────────────────
prov(p.add(k)) = (a, off + k·S)         (p.add(k)).term = p.term + k·S

── Slice bound ──
prov(p) = (a, 0)    a.slice_len = len
─────────────────────────────────────────
InBound(p, i) ⟺ i < len

── Byte-range case split (generic S) ──
S = 0                                          S ≥ 1
──────────────────────                        ──────────────────────
x·S = y·S = 0   (byte range vacuous)           x·S ≤ y·S ⟺ x ≤ y

── Integer arithmetic ──
i < len
─────────────
i + 1 ≤ len

── Fast-path flags ──
non_null(p)          init(p)             align_n(p) = A         in_bounds(p)   n = 1
────────────        ───────────          ─────────────────      ────────────────────────
NonNull(p)          Init(p, T, 1)        Align(p, T)            InBound(p, T, 1)

── Ptr2Ref ──
Ptr2Ref(p, T) ⊢ Init(p,T,1) ∧ NonNull(p) ∧ Allocated(p,T,1) ∧ InBound(p,T,1) ∧ Align(p,T) ∧ Alias(p)

── Alias (hazard) ──
  对象：解引用后产生引用（&）的操作（&*p / &mut *p / from_raw_parts 等）；
        不加 & 的直接读写（*p / *p = ...）走 Deref/ReadMemory，不是 Alias。

  classify origin — resolve_origin(p) → o, by o's type:
    &mut T → MutRef        &T → SharedRef        *const T / *mut T → RawPtr
    Box/Vec/NonNull → Owned

  classify view — deref mutability:
    &*p → SharedView (read);   &mut *p → UniqueView (write)

  judge by (view, origin):
    SharedView:  MutRef → ✓   SharedRef → ✓   RawPtr → ?
    UniqueView:  MutRef → ✓   SharedRef → ✗   RawPtr → ?
    (Owned origin → ✓; a raw-pointer *parameter* origin → Unknown)

  defer (?) — only for raw-pointer origins:
    local view (does not escape) → ✓
    escapes:  private raw field, not written/exposed by a safe method → ✓ ; else ✗

  local hazard scan — after the view is produced:
    when SharedView:  raw write via an origin → ✗ (shared view is read-only)
    when UniqueView:  any raw access via an origin → ✗ (unique view is exclusive)

  ✓ = safe   ✗ = violation   ? = defer   Unknown = cannot decide
  get_unchecked:  resolve_origin(_4) = _1 (&self) — SharedRef + SharedView ⇒ ✓
```

### 10.1.3.2 get_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(InBound(self, index)))]
pub const unsafe fn get_unchecked_mut<I>(&mut self, index: I) -> &mut I::Output
where
    I: [const] SliceIndex<Self>,
{
    unsafe { &mut *index.get_unchecked_mut(self) }
}
```

**MIR.** On the mutable receiver the shape is the same as `get_unchecked` (§10.1.3.1) — one `InBound` checkpoint at `get_unchecked_mut`, then the `&mut *` deref (Ptr2Ref checkpoint) — except the mutable reference reborrows into a longer chain: each `&mut *` is a distinct borrow edge through the opaque `I::Output` projection, and only the first is a checkpoint.

```text
bb0: _7 = move _2;
     _8 = &raw mut (*_1);
     _6 = <I as SliceIndex<[T]>>::get_unchecked_mut(move _7, move _8) -> [return: bb1, unwind: bb3];
bb1: _5 = &mut (*_6);   // &mut * — raw-pointer deref (Ptr2Ref checkpoint)
     _4 = &mut (*_5);   // safe reborrows, no checkpoint
     _3 = &mut (*_4);
     _0 = &mut (*_3);
bb2: return
```

**Verification.** Identical to `get_unchecked`, with two differences: the `&mut [T]` receiver, and the `Alias` hazard resolving to `&mut self` (exclusive) instead of `&self` (shared). Both checkpoints discharge the same way; the trailing `_4/_3/_0 = &mut (*…)` are safe reborrows.

### 10.1.3.3 swap_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(a, "[0,self.len())")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(b, "[0,self.len())")))]
pub const unsafe fn swap_unchecked(&mut self, a: usize, b: usize) {
    assert_unsafe_precondition!(
        check_library_ub,
        "slice::swap_unchecked requires that the indices are within the slice",
        (len: usize = self.len(), a: usize = a, b: usize = b,) => a < len && b < len,
    );
    let ptr = self.as_mut_ptr();
    unsafe {
        ptr::swap(ptr.add(a), ptr.add(b));
    }
}
```

**Verification Targets.** Three unsafe callsites — the two `ptr.add` pointer-arithmetic calls and `ptr::swap`:

```rust
// core::ptr::mut_ptr::add
#[rapx::requires(InBound(self, T, count))]

// core::ptr::swap
#[rapx::requires(ValidPtr(x, T, 1))]
#[rapx::requires(Align(x, T))]
#[rapx::requires(ValidPtr(y, T, 1))]
#[rapx::requires(Align(y, T))]
```

**Path.** `assert_unsafe_precondition!` lowers to a `precondition_check` panic guard (guarded by `UbChecks`), which is not an unsafe checkpoint; the three unsafe callsites are reached on the normal path `bb0 → bb1 → bb2 → bb3 → bb5 → bb6` (`ptr.add(a)`) → `bb7` (`ptr.add(b)`) → `bb8` (`ptr::swap`).

**MIR.** The statements on that path:

```text

bb7: _17 = ptr.add(copy _11, _3);   // ptr.add(b)  ← checkpoint (2)
```


### 10.1.3.4 as_chunks_unchecked

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(N, "[1,)")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(len(self) % N == 0)))]
pub const unsafe fn as_chunks_unchecked<const N: usize>(&self) -> &[[T; N]] {
    assert_unsafe_precondition!(
        check_language_ub,
        "slice::as_chunks_unchecked requires `N != 0` and the slice to split exactly into `N`-element chunks",
        (n: usize = N, len: usize = self.len()) => n != 0 && len.is_multiple_of(n),
    );
    // SAFETY: Caller must guarantee that `N` is nonzero and exactly divides the slice length
    let new_len = unsafe { exact_div(self.len(), N) };
    // SAFETY: We cast a slice of `new_len * N` elements into
    // a slice of `new_len` many `N` elements chunks.
    unsafe { from_raw_parts(self.as_ptr().cast(), new_len) }
}
```

**Verification Targets.** Two unsafe callsites:

(1) `exact_div(self.len(), N)` — requires a non-zero divisor;

(2) `from_raw_parts(self.as_ptr().cast(), new_len)`:

```rust
// core::slice::raw::from_raw_parts
#[rapx::requires(NonNull(data))]
#[rapx::requires(ValidPtr(data, T, len))]
#[rapx::requires(Init(data, T, len))]
#[rapx::requires(Alive(data, 'a))]
#[rapx::requires(Alias(data))]
#[rapx::requires(Align(data, T))]
#[rapx::requires(ValidNum(size_of(T) * len <= isize::MAX))]
```

**Path.** After the `precondition_check` guard, the two callsites are reached in order on the normal path `… → bb7 → bb8 → bb9 → bb10` (`exact_div` in `bb7`, `from_raw_parts` in `bb10`).

**MIR.** The statements on that path:

```text
bb6:  _8 = len(&(*_1));
bb7:  _7 = exact_div(move _8, const N);                  // ← checkpoint (1)
bb8:  _12 = as_ptr(&(*_1));
bb9:  _11 = ptr.cast::<[T; N]>(move _12);
bb10: _10 = raw::from_raw_parts(move _11, copy _7);      // ← checkpoint (2)
bb11: _0 = &(*_10);
```

**Verification.**

```text

            _1.term = data_alloc.base, _1.prov = (data_alloc, 0), _1.flags = { non_null, aligned, init, in_bounds }
               slice type invariant (JSON `[T]` entry):
                 NonNull(_1)           : _1.term ≠ 0

                 ValidNum(..)          : len * sizeof_T ≤ isize::MAX
                 Allocated(_1, T, len) : len·sizeof_T ≤ data_alloc.size

            ValidNum(N, [1, ∞))           →  N ≠ 0
```

### 10.1.3.5 as_chunks_unchecked_mut

```rust
#[cfg_attr(rapx, rapx::verify)]
#[cfg_attr(rapx, rapx::requires(ValidNum(N, "[1,)")))]
#[cfg_attr(rapx, rapx::requires(ValidNum(len(self) % N == 0)))]
pub const unsafe fn as_chunks_unchecked_mut<const N: usize>(&mut self) -> &mut [[T; N]] {
    assert_unsafe_precondition!(
        check_language_ub,
        "slice::as_chunks_unchecked requires `N != 0` and the slice to split exactly into `N`-element chunks",
        (n: usize = N, len: usize = self.len()) => n != 0 && len.is_multiple_of(n)
    );
    let new_len = unsafe { exact_div(self.len(), N) };
    unsafe { from_raw_parts_mut(self.as_mut_ptr().cast(), new_len) }

```

**Verification Targets.** Same two callsites as `as_chunks_unchecked` — `exact_div(self.len(), N)` and `from_raw_parts_mut(self.as_mut_ptr().cast(), new_len)` (the `_mut` variant of the `from_raw_parts` contract, adding `Alias`).

**Path.** `… → bb7 → bb8 → bb9 → bb10` (`exact_div` in `bb7`, `from_raw_parts_mut` in `bb10`).

**MIR.** The statements on that path:

### 10.1.3.27 get_disjoint_check_valid

```rust
#[cfg_attr(rapx, rapx::verify)]
fn get_disjoint_check_valid<I: GetDisjointMutIndex, const N: usize>(
    indices: &[I; N],
    len: usize,
) -> Result<(), GetDisjointMutError> {
    for (i, idx) in indices.iter().enumerate() {
        if !idx.is_in_bounds(len) {
            return Err(GetDisjointMutError::IndexOutOfBounds);
        }
        for idx2 in &indices[..i] {
            if idx.is_overlapping(idx2) {
                return Err(GetDisjointMutError::OverlappingIndices);
            }
        }
    }
    Ok(())
}
```

**Verification Targets.** No unsafe callsites — this is a pure O(n²) validation loop over the indices (`is_in_bounds` and `is_overlapping`). It is annotated with `#[rapx::verify]` so RAPx treats it as the trusted precondition generator for `get_disjoint_mut`.

**MIR.** The nested-loop shape (outer `next` at `bb4`, `is_in_bounds` at `bb7`, inner `next` at `bb14`, `is_overlapping` at `bb16`):

```text
bb4:  _12 = <Enumerate<Iter<I>>>::next(...);        // (i, idx)
bb7:  _20 = <I as GetDisjointMutIndex>::is_in_bounds(&idx, len);   // idx.is_in_bounds(len)
bb14: _33 = <Iter<I>>::next(...);                   // idx2 in indices[..i]
bb16: _39 = <I as GetDisjointMutIndex>::is_overlapping(&idx, &idx2);
```

**Verification.**

```text
entry   _1 = indices (&[I; N]), _2 = len (usize)

# outer loop: for (i, idx) in indices.iter().enumerate()
_20 = idx.is_in_bounds(len)
          check  Ok ⇒ idx in bounds    (otherwise Err(IndexOutOfBounds))

# inner loop: for idx2 in indices[..i]
_39 = idx.is_overlapping(idx2)
          check  Ok ⇒ no pair overlapping    (otherwise Err(OverlappingIndices))

result: SOUND (no unsafe checkpoints; pure validation loop)
```

The nested loops prove that an `Ok` return implies every index passed `is_in_bounds` and no pair `is_overlapping` — the facts that `get_disjoint_mut` then relies on.
